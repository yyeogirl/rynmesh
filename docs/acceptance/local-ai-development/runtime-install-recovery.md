## 问题与修复

原生运行时解压失败、安装完成记录写入失败，或解压后取消时，磁盘上可能已经有可执行文件。原来的查找逻辑会直接复用该文件，导致重试跳过安装，即使配套文件还没准备好。

托管下载目录现在必须有当前版本的安装完成记录才允许复用。记录在解压结束、可执行权限设置完成且取消检查通过后写入。修复安装开始覆盖文件前先撤销旧完成记录，失败时不能沿用旧记录。已完整安装的运行时和显式配置的运行时继续按原顺序查找。

这条记录只证明安装流程完成；模型是否就绪仍由加载、健康检查和推理自检决定。没有完成记录的旧目录在下次安装时重新下载并解压；不据此删除模型或会话。

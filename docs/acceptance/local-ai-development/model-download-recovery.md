# 模型下载中断与续传

日期：2026-09-12。分支：`codex/user-product-development`。对应 AI03、AI04。
完整 macOS 打包应用验收仍待执行。

## 本次修复

- 连接提前关闭时，保留实际收到的文件前缀并提示继续下载；不会把尚未收完的数据当作校验失败而隔离。
- 续传前检查响应的偏移、范围、总大小、长度和内容编码。无效响应不能追加或覆盖原有进度；合法的完整响应或从零开始的响应仍支持重新下载。
- 源端提前返回范围不可满足时，若文件尚未达到固定大小，保留进度等待重试。完整文件仍必须通过 SHA-256 校验。
- 开始下载前检查取消；校验期间收到取消时不将临时文件发布为完整模型，重试可重新校验。
- 下载阶段明确显示尚待校验；安装页把中断与无效响应解释为可重试、原进度保留，不显示模型已就绪。

## 可重复的验证

后端测试位于 `tests/test_model_download_recovery.py`，使用 Windows 上真实的回环 HTTP 服务和 urllib 响应解析。下载入口仍要求 HTTPS；测试只替换传输入口，故本记录不证明公网或 TLS 行为。

| 场景 | 实际结果 |
|---|---|
| 6400 字节合成文件只发送 1024 字节就关闭连接 | 临时文件保留前 1024 字节，未生成完整文件或损坏文件 |
| 新 Python 进程继续上述下载 | 请求从 1024 字节开始，完整文件 SHA-256 匹配，内容一致 |
| 缺失范围、错误偏移、错误总大小、长度与范围不符、非法长度、压缩编码、提前返回 416 | 原有 256 字节前缀保持不变；修复响应后仍从 256 字节继续并校验成功 |
| 发请求前取消 | 源端收到零次请求，未创建下载文件 |
| 完整文件校验阶段取消 | 临时完整文件保留，不发布正式文件；重试校验后才发布 |

新增测试修复前首先复现了截断、缺失范围、错误偏移、编码及提前 416 五种失败。后续补齐响应长度、总大小和取消检查。相关后端测试为 83 passed / 4 skipped（12.82 秒）。

安装页面组件测试 `webapp/src/screens/Services.llm.test.tsx` 为 26 passed，包含中断及无效响应的提示；保留已有安装取消与重试交互覆盖。

最终全量回归：后端 **1410 passed / 29 skipped**（283.26 秒，5 条既有弃用警告）；前端 **218 passed / 42 files**（33.98 秒）。TypeScript、生产构建、全后端 Ruff 和差异检查通过。生产 JS 为 `index-rwv6pUbY.js`，638.54 kB；构建保留原有大于 500 kB 的体积提示。95 条需求清单校验通过，各项验收状态未因测试数量而提升为完整通过。

## 证据范围

这些测试使用合成文件，未下载真实大模型；没有运行推理，也没有操作打包桌面窗口。独立进程验证的是下载文件跨进程恢复，不替代应用安装任务、运行时和健康状态的完整重启验收。

# 离线阅读开发验证

日期：2026-09-11。当前为后端与页面开发候选，尚未完整通过 OFFLINE01–10 和通用验收。

## 已接入

- 新增独立 `offline_reading` 路由包，复用节点 Owner 鉴权、后台任务注册表、原子写入、节点密钥加密和现有正文提取模块。
- 普通收藏不会创建离线副本。明确下载后生成一个任务，重复请求复用活动任务；正文未提交前，读取接口返回未下载。
- 状态区分排队、下载、校验、可用、部分可用、失败、取消请求、已取消和已清理。记录经过校验的字节，不虚构百分比或 HTTP 字节续传。
- 正文和每张已处理图片分别写入加密检查点。重启只复用能重新认证的检查点；任务身份和执行令牌阻止取消、清理或重启之前的迟到结果写回。
- 更新由用户明确请求；新副本提交前保留旧正文、原下载时间和图片版本。图片接口绑定副本版本，更新后旧图片 URL 返回版本变化。
- 单项加密文件限制 16 MiB，总预算 256 MiB，其中为元数据保留 4 MiB。网页输入最多 8 MiB，正文最多 4 MiB，图片最多 8 张、每张 2 MiB；图片尺寸及像素数量也有上限。原子替换计入旧文件仍占用时的峰值空间。
- 单条和全部清理先返回副本数、暂存任务数、大小及确认标识；期间任务变化会使旧确认失效。清理限定在离线包，保留收藏、阅读进度和独立导入副本；取消收藏也不会自动清理下载。
- 公网页面重新获取正文，不把有时效的阅读缓存当成明确下载。来源和图片地址逐次验证，阻止内网、凭证 URL、主动脚本和 SVG；固定已校验地址连接，保留 TLS 主机校验，不发送节点凭证、Cookie 或 Referer。
- 网络下载由一个受监督子进程执行，父进程限制 DNS、连接、响应头和正文的总时限，并能取消、终止和回收。仅开发验收可通过 `RYNMESH_OFFLINE_ALLOW_LOOPBACK=1` 允许回环来源，默认拒绝。
- 已导入的好友文档作为接收者的独立本地副本读取，先使用现有导入模块验证内容。此入口不向原发布者请求新版本。
- 网络和存储失败既记入任务安全错误码，也交给后台注册表统计；损坏离线数据不阻止节点应用创建。
- 清理或替换前检查关联文件版本，未知版本拒绝并保留元数据引用；无引用的未来版本文件也不由当前代码删除。已清理的记录可让出元数据名额，不会形成永久的下载次数限制。

## 清理文件失败与重启恢复

2026-09-11，在 `1ee099b` 基础上修复 OFFLINE07/G08 的一个恢复缺口：旧清理先清空下载元数据，再调用通用 GC；文件被占用时删除失败，而原审核令牌已无法重试。当前实现将下载写入屏障与 `ryn.offline-cleanup.v1` 清理凭据一起写入原加密状态文件；只有已审核的文件被删除，文件删除和完成状态确认后才报告完成。

# 登录提示不再替换离线正文

对应 OFFLINE05、OFFLINE08。Windows / Python 3.12，合成 HTML、真实加密离线存储，无真实账号、密码或外网请求。

复现：先下载可读文章，来源随后返回 HTTP 200 的登录页面。页面正文容器中有一段登录说明和密码表单。旧实现把说明段落当成文章，更新任务成功并替换旧副本；新增回归用例实际失败，未抛出应有的访问限制错误。

修复：现有正文提取器标记选中正文容器内的密码表单，离线下载返回已有的 `offline_source_access_required`。任务失败沿用已有恢复流程，旧正文、下载时间和任务版本保持可读。位于被忽略侧栏中的登录表单不影响公共文章下载。

验证：`tests/test_offline_reading.py`、`tests/test_offline_material.py`、`tests/test_reader_and_steering.py` 合计 53 项通过，18.79 秒；Ruff 通过。包括原副本完整保留，以及有独立登录侧栏的正常文章仍可下载。已有一项 Starlette TestClient 弃用警告。

范围：这是已复现的密码表单结构修复，不代表识别所有网站的付费墙、短信/SSO 登录或验证挑战。完整登录页面矩阵、打包桌面及原有未验流程仍未完成，原用例状态不改为通过。

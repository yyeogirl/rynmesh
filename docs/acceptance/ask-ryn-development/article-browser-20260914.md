# Ask Ryn 文章问答、预算与历史引用 · 2026-09-14

环境：Windows AMD64，本机生产节点和 Web 构建，正常安装的原生 llama.cpp / Qwen2.5-0.5B CPU 模型。复用已验安装的专用节点，新建两段会话；没有预置问答、替换模型响应或再次安装。来源是明确标记的合成文章，含一段要求泄露历史、改变接收方的恶意引用文字。本次不是桌面安装或公网测试。

## 实际流程

1. 在模型管理页启动原已安装模型。通过 For You 添加合成 RSS，打开短文，点击 Ask about this content。Ask 首页显示来源、本机接收方和模型状态；确认后创建新的独立会话。
2. 输入关于树木数量的问题，在发送前审核接收方、来源、474/474 字节和完整预算。键盘 Tab、Return 确认后，真实模型整段返回 `Three`，数量正确。模型未生成要求的行内引用标号，这个限制保留；应用提供的 Sources supplied for this answer 能查看实际材料。
3. 展开回答引用，显示 474 字节完整片段与原地址。侧栏链接和聊天页面使用相同会话 ID。
4. 从侧栏进入历史页，复现回答存在但引用入口缺失。修复后，历史页可以展开相同来源、字节说明和本地片段。
5. 打开长文并新建另一段会话，以较长的真实首轮问题形成历史。正文总长 65,404 字节；发送预览明确显示只提供 746 字节、TRUNCATED，完整输入预算 2808 + 框架 1024 + 输出 256 = 4088，不超过 4096。实际模型返回 `3`。
6. 在同一会话问树木种植月份。预览提示省略 1 条旧历史，正文纳入 1408/65404 字节，预算 2129 + 1024 + 256 = 3409。真实模型返回 `April`。三次问答归档中的 prompt 摘要、来源 ID 和实际字节数与对应发送预览完全一致，订单均为 local_runtime、金额为 0。
7. 为取消验收请求较长答案，但该次真实生成在取消操作前已完成，没有发送取消请求。只保留已完成观察，不能计为生成中取消或 GPU 停止证据。
8. 停止并重启节点，PID 60152 → 23780。短会话两条消息、长会话六条消息的完整历史摘要保持一致，任务及来源绑定未变化。模型 stopped / ready=false，发布仍关闭；历史页能读回答、打开原引用片段。

2026-09-14，基于 `4a27a3f` 的本地候选。补充 SEARCH05、SEARCH11、G06；不改变完整验收状态。

搜索接口现在对正常、鉴权失败、参数错误及内容失效响应统一返回 `Cache-Control: no-store`。前端搜索请求使用 `cache: no-store`，重新访问节点验证当前数据，避免读取此前可能存在的 HTTP 缓存。这不会清除已经保存的用户副本，也不代表擦除了所有旧浏览器数据。

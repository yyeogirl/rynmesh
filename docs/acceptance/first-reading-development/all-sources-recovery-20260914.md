# 全部来源不可用：空目录、缓存与重启

日期：2026-09-14。Windows 生产节点和浏览器，新的空数据目录，14 个桌面默认公共来源，无模型、无好友、无预置内容。对应 READ05、READ06 的部分分支，以及 READ01 的真实内容要求。

## 故障方式与边界

`scripts/accept_reading_network.py` 在 loopback 18932 提供 HTTPS CONNECT 代理。仅验收启动命令设置代理环境变量；未修改系统代理、防火墙或网卡。offline 模式拒绝来源连接；online 模式转发真实 TLS 字节，不解密正文或提供伪造响应。控制目录的 `mode.txt` 切换状态；产品数据没有被辅助程序改写。

本轮证明的是来源连接全部失败时的真实浏览器/节点行为，不是打包应用、整台设备断网或跨公网验收。浏览器对外部图片的请求不受这个节点代理控制，因此不以本记录证明完整离线资源或隐私网络审计。

## 实际发现与修复

1. 无缓存且 14/14 来源失败时，首次引导正确提示重试，但首页仍返回两张 starter 建议，并计为两条可用推荐。它们没有可读正文，仍出现 Safety passed 等卡片信息。推荐接口现已移除 starter 回退及对应的新反馈入口；空数据或真实候选全部被隐藏时返回空列表。旧画像数据没有被擦除。
2. For You 在 0/14 健康时仍显示 using healthy sources、声称保留可用推荐。现在分别显示 waiting for connection 或 using cached content；无缓存时说明尚无内容并提供 Refresh 恢复路径。

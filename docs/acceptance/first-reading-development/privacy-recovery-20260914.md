# 推荐数据：导出、重置与失败恢复

2026-09-14，Windows 生产节点、浏览器和专用首次阅读验收目录。复用前次真实页面产生的四条反馈事件（包含撤销和替代状态）、一条收藏与已提取正文。没有改写这些产品记录来伪造重置结果。对应 READ10 及部分 G03/G04/G06/G07/G08；不是完整产品或打包桌面验收通过声明。

## 实际发现和修复

- 节点停止后点击 Export reading & preferences (JSON)，旧页面没有失败提示。现在显示加载状态、阻止重复请求，失败时提供连接检查与重试说明，并将焦点移到结果。成功文案只声明已准备并请求下载，提示检查浏览器下载。
- 隐私摘要读取失败原先没有恢复入口，现在显示 Retry data summary。
- 文件占用导致重置失败时，旧弹窗只显示 HTTP 500，焦点落到弹窗外。现在说明擦除尚未完整确认及连接/存储恢复动作；公共确认弹窗将焦点移到错误，键盘可继续取消或重试。

## 页面执行记录

1. Settings → Privacy & data，普通导出按钮触发成功响应与下载请求。只读核对同一 HTTP 导出接口：四条反馈事件均在，操作、主题、平台、来源、时间和撤销字段与解释接口一致。
2. 停止节点后点击导出，复现无错误提示；修复并加载新构建后再次停止节点，页面明确显示未取得完整导出，焦点在错误上。
3. 重启同一节点，不刷新页面，Tab → Enter 重试导出，显示准备完成、已请求下载，焦点移到该结果。
4. Reset learning 打开确认范围，初始焦点为 Cancel。Enter 取消后焦点回到 Reset learning；API 核对画像和收藏均未改变。
5. 使用已有 Windows 文件占用辅助程序阻止 `recommendation-profile.json` 原子替换。页面确认后失败；四条反馈和画像摘要完全不变。最终构建复验错误说明与错误焦点，未显示擦除成功。
6. 释放占用，从同一失败弹窗用 Tab → Tab → Enter 重试。反馈与信号归零；收藏、完整阅读历史摘要、318 条发现缓存、一个正文缓存和来源目录摘要保留。
7. 重启节点到不同 PID，画像和阅读历史摘要保持重置后的值；导出中的反馈事件仍为空。未擦除审计日志，新增的重置审计事件符合选定范围。

只读结果及断言见 [privacy-checkpoints-20260914.json](privacy-checkpoints-20260914.json)，由 `scripts/observe_recommendation_privacy.py` 生成。辅助观察不执行产品擦除，也不记录导出正文、密钥、文章 URL 或个人路径。

## 隐私核对范围

- 导出响应不含该节点已检查的 Ed25519/X25519 身份密钥；转发头模拟的未认证远程导出请求返回 401。
- 对实际缓存中的 12 个长正文块，逐一检查本地助手审计字段与公开节点响应，未出现这些正文。这个检查不能证明其他日志、诊断和所有网络请求均不含私有数据。
- `tests/test_recommendation_privacy.py` 执行真实 Digest 排名/摘要组装路径，使用记录请求的测试 Provider；原始方向、反馈标题、私有信号和事件 ID 的 canary 均未进入两次摘要请求或来源请求 URL。请求确实包含预期公共元数据，避免空调用假通过。它是模型接口边界测试，未运行远程模型或全流量抓包。
- 检查代码中的 `DigestService._enrich`：请求由标题、来源和公共摘要构成；推荐画像只参与本地排序。实际浏览器夹具没有配置模型，也没有开启公共注册。

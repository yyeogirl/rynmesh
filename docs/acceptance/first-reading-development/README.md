## 本次实现

- 引导打开真实正文后才记录阅读；读取或收藏失败保留重试入口。
- 单来源健康、失败次数、检查/成功时间、保留缓存及单来源重试。
- 推荐反馈保留每次 More/Less/Hide 的操作、时间、主题、平台、来源与有效状态。
- 单条撤销重新计算本地推荐；重复请求不重复计权，写失败不伪造成功。
- 阅读位置保存与恢复；支持回到前面重读，显示正文截断提示。
- 首页、推荐页和已读列表接入同一正文读取路径；历史记录缺少推荐证据时仍可阅读。

## 数据规则与迁移

首次引导只存里程碑。旧 `first-success.json` 迁移到 `first_run/state.json` 前备份，
未知字段保留，未来版本不覆盖，进度写失败不阻断已成功的收藏/阅读记录。

推荐画像从版本 1 迁移到版本 2，迁移前写 `.migrated` 备份。版本 1 每篇内容只保留最后
一次反馈，所以只恢复这些已保存操作，界面明确标注，不虚构更早的历史。
版本 2 按操作日志重新计算当前信号；每篇内容最后一条未撤销操作生效。
撤销当前操作可恢复前一次；撤销已被覆盖的操作不改变后来有效操作。

旧 Digest 派生权重仍在原文件中供导出，但接入统一画像时不再重复应用。
显式清空画像同时擦除新反馈日志、迁移备份和旧派生偏好。

## Windows 基线修复

- 纯文本提取统一换行符；runtime HTTPS 下载测试使用对应平台的归档样本。
- Windows 的原子替换遇到临时共享/访问冲突时有限重试，永久失败仍保留旧文件。
- 私有临时文件在写入正文前设置受保护 DACL，仅当前用户、SYSTEM 和管理员可访问；
  邮箱目录也检查真实 DACL。无法设置时写入失败，不把 POSIX 权限位当作 Windows 权限证据。
- 权限实现参考 [Python chmod 平台说明](https://docs.python.org/3/library/os.html#os.chmod)
  与 [Windows SetNamedSecurityInfoW](https://learn.microsoft.com/en-us/windows/win32/api/aclapi/nf-aclapi-setnamedsecurityinfow)。

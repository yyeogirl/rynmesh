# 03 统一 Ask Ryn

状态：需求草案，待开发与验收。优先级：第二批，覆盖 #24 / #25。

## 1. 目标与流程

一个入口完成普通问答、文章问答和历史续聊，并清楚说明使用哪个模型、内容发送给谁。

打开 Ask Ryn/文章提问 → 选择会话与模型 → 查看接收方 → 提问 → 等待回答 → 查看引用 → 重启后继续。

## 2. 功能需求

| 功能 | 具体规则 |
|---|---|
| 统一入口 | 主页面、快捷侧栏、文章提问共用会话，移除预设示例聊天记录 |
| 会话管理 | 新建、命名、查找、继续、删除；完整会话存于本机节点，浏览器不维护另一份权威历史 |
| 旧会话迁移 | 保留原 Provider、服务键、时间和消息；重复迁移不重复导入，失败可恢复 |
| 普通问答 | 输入后展示提交/生成状态；完整答案一次返回是受支持路径 |
| 文章提问 | 携带选中文章，发送前显示来源，允许移除上下文 |
| 引用与预算 | 使用节点提取正文；显示真实来源和截断提示；预算包含历史、正文、问题和预留输出 |
| 模型选择 | 显示提供者、模型、上下文窗口、价格和就绪/忙碌/不可达状态；未知价格不能显示免费 |
| 切换规则 | 历史保持原服务键；切换创建或打开新服务会话，不自动转发旧历史；携带旧内容需再次确认 |
| 取消与重试 | 已请求取消不等于计算已停止；运行与订单身份关联，超时/重启后先核对原任务再重试 |
| 权限边界 | 区分本地、好友及其他远端；只有有效关系可标为好友；外部文章当作数据，不是操作指令 |

## 3. 异常与恢复

- 无模型时保留输入与历史，提供安装或选服务入口，不伪造回答。
- 未就绪、忙碌、连接容量不足、不可达分开提示，提供对应等待、重试或切换动作。
- 材料失效时显示缺失，允许移除/重新读取，不能假装已经引用。
- 生成超时或节点重启时显示待核对/已中断，不能自动重复下单。
- 迁移或保存失败保留可恢复数据，确认节点保存成功前不删除旧记录。

## 4. 范围与复用

复用 Ask Ryn UI、#24 服务切换、#25 内容问答和既有任务/订单能力。
节点会话存储不等于多设备同步，后者由需求 08 提供。
首版不要求流式输出，不包含自主改文件、发布或执行外部操作。

## 5. 验收标准

同时满足 [通用验收标准](README.md#通用验收标准)。

| 编号 | 操作或条件 | 通过条件 |
|---|---|---|
| ASK01 | 全新安装打开入口 | 无伪造历史，有模型可问答，无模型有设置入口 |
| ASK02 | 页面提问，从侧栏打开，再重启 | 同一会话 ID、相同历史与任务状态，完成的回答可继续 |
| ASK03 | 迁移旧会话，重复执行并模拟失败 | 不重复、不丢服务键；失败保留原数据，重试可完成 |
| ASK04 | 从文章进入问答 | 来源可见，引用对应实际提供材料，并可返回打开 |
| ASK05 | 超长正文叠加长历史 | 总预算不越界，截断或删减提示发送前可见 |
| ASK06 | 从服务 A 切换 B | 显示 B 接收方；A 历史保持绑定；未经确认 B 收不到旧内容 |
| ASK07 | 模拟未就绪、runtime_busy、p2p_capacity_exhausted、不可达 | 原因和动作分别正确，不全部显示节点离线 |
| ASK08 | 生成中取消、超时、重启后重试 | 不提前声称 GPU 已停；核对原任务，不重复发单与结算 |
| ASK09 | 文章含要求泄露数据或执行操作的文字 | 不触发自动授权、切换接收者或执行外部操作；文章按引用处理 |
| ASK10 | 删除/导出会话并检查日志 | 数据范围明确，导出无凭证，普通日志无输入输出正文 |

验收分别覆盖入口、迁移、模型切换、引用预算和任务结算，不能仅凭去 seed 或改名关闭 #24 / #25。

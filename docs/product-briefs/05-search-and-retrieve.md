# 05 搜索与找回

状态：需求草案，待开发与验收。优先级：后续优先，依赖内容和节点会话数据可用。

## 1. 目标与流程

用户不必记住内容保存在哪个页面，用一个搜索框找到看过的文章、好友发来的内容和聊过的问题。

输入关键词 → 查看混合结果 → 按类型/时间筛选 → 打开内容或消息位置 → 返回原搜索结果。

## 2. 搜索范围

| 类型 | 搜索字段 | 点击结果 |
|---|---|---|
| 已保存内容 | 标题、来源、已获取的正文 | 打开阅读器 |
| 阅读历史 | 标题、来源、已获取的正文 | 返回对应内容及已有阅读位置 |
| 好友分享 | 已收到的文本、卡片标题/来源、已授权获取的正文 | 打开分享记录或内容卡片 |
| 聊天记录 | 本机保存的 Ask Ryn 和好友聊天文本、会话标题 | 打开对应会话并定位命中消息 |

仅索引本机已有且当前允许使用的数据。未下载/未确认获取的正文不参与全文搜索，
附件首版只搜索名称及已有元数据，不为了搜索自动下载、扫描好友设备或访问云端。

## 3. 功能规则

- 统一入口可从主要页面到达；支持中文词组、英文关键词和常见混合输入。
- 支持按类型、时间区间、来源或好友缩小范围；默认按相关度排序，可改为最近。
- 每条结果显示类型、标题/会话、来源或好友、时间、匹配片段；高亮匹配文字。
- 同一内容同时在收藏、历史、分享中时合并为一个内容结果，保留来源标签；会话中的不同消息不按文本相同随意合并。
- 返回列表后保留关键词、筛选和滚动位置；旧请求结果不能覆盖更新的关键词结果。
- 新增、编辑、删除后更新搜索索引；索引损坏可重建，重建不删除原数据。
- 重建期间显示索引中或部分结果，不将暂未索引解释为没有内容。
- 权限在返回结果和打开内容时均检查；旧索引不能泄露已失去授权内容的片段。
- 接收者此前明确保存的独立副本仍属于本地保存记录，撤销关系不能远程收回；仅靠好友在线授权访问的内容应隐藏。

## 4. 异常与恢复

无结果时提示检查关键词或清除筛选；空输入展示说明，不自动泄露全部记录。
原文已删除/来源失效时说明不可打开，仍可打开的本地副本单独标识。
离线可搜索已索引记录；未缓存正文明确提示联网后获取。索引失败可重试/重建，不影响原内容阅读。

## 5. 本期边界

首版做本地关键词搜索，不要求语义搜索、OCR、互联网搜索或远程设备全文检索。
分页加载，建议每页 20 条；建议在记录的参考桌面、索引就绪、1 万条合成记录下，
20 次中英文常用查询首屏响应的 p95 不超过 2 秒。冷建索引耗时另行记录，不混入查询指标。

## 6. 验收标准

同时满足 [通用验收标准](README.md#通用验收标准)。

| 编号 | 操作或条件 | 通过条件 |
|---|---|---|
| SEARCH01 | 四类数据分别放入不同合成关键词 | 每类均可找到，点击打开正确内容或命中消息 |
| SEARCH02 | 中文词组、英文及中英混合查询 | 按约定匹配，不因中文无空格而完全失效，匹配片段正确 |
| SEARCH03 | 切换类型/时间/好友筛选，再返回列表 | 仅保留符合条件结果，关键词、筛选和位置保持 |
| SEARCH04 | 同一内容同时收藏、读过、被分享 | 一个内容结果包含多个来源入口；不同消息不被误合并 |
| SEARCH05 | 修改、增加和删除记录 | 索引正常时建议 5 秒内更新；删除后旧索引也不能继续返回正文片段 |
| SEARCH06 | 失去好友访问授权，保留旧索引 | 受保护结果与片段立即被权限检查过滤，直接打开也拒绝 |
| SEARCH07 | 未获取正文、断网、来源删除分别测试 | 不假装搜过未取得正文；本地数据可搜；不能打开时有真实原因 |
| SEARCH08 | 连续快速输入并使旧请求晚返回 | 页面最终显示最新关键词结果，不被旧响应覆盖 |
| SEARCH09 | 索引损坏后重建，期间重启 | 原数据无损，状态可见，重建完成后查询恢复 |
| SEARCH10 | 参考桌面、1 万条已索引合成记录，20 次查询 | 记录 p95，建议首屏不超过 2 秒；分页无重复遗漏 |
| SEARCH11 | 查询含私有关键词，检查网络和日志 | 搜索不上传关键词或正文，日志只记录必要状态和耗时 |

需提交：四类数据检索、权限变更、索引恢复、参考数据集与查询耗时记录。

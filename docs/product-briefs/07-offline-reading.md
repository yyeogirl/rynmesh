# 07 离线阅读

状态：需求草案，待开发与验收。优先级：后续，依赖阅读器、正文提取和内容授权。

开发进展：已接入节点端明确下载、加密检查点、取消/恢复、旧版保留、下载页面和搜索清理联动；完成浏览器中来源关闭后的重启阅读验证。打包桌面及完整权限流程仍待验收。见[开发验证记录](../acceptance/offline-reading-development/README.md)，不代表以下验收全部通过。

## 1. 目标与流程

用户提前保存想读的正文，在断网、通勤或网络不稳定时仍可阅读，并清楚知道哪些内容真正下载完成。

收藏/阅读页选择离线下载 → 查看实际状态 → 下载完成 → 断网打开 → 继续阅读 → 按需清理。

## 2. 功能需求

| 功能 | 具体规则 |
|---|---|
| 下载入口 | 收藏时可选择下载，已有收藏可单独下载；普通收藏不自动等同于全文下载 |
| 下载内容 | 首版保存可提取正文、来源元数据和受大小限制的必要图片，不运行网页脚本或嵌入追踪资源 |
| 支持判断 | 无可提取正文、需登录、已失授权时说明无法下载，不保存一份空页面当成功 |
| 状态 | 排队、下载中、校验中、可离线、部分可用、失败、已清理；进度使用真实字节或阶段 |
| 可离线定义 | 正文保存并校验成功，阅读器能从本地打开；图片缺失时标记“正文可离线，部分图片缺失” |
| 中断恢复 | 保留可验证检查点，支持取消/重试；重复点击不生成重复副本，失败暂存不会冒充正文 |
| 离线列表 | 已下载列表可筛选，展示标题、来源、下载时间、大小及状态 |
| 本地阅读 | 断网与重启后直接读取本地正文；外链或未下载媒体显示需要联网，由用户主动打开 |
| 版本 | 显示下载时间；更新正文由用户触发，新版本验证成功前保留旧版可读副本 |
| 存储管理 | 显示总占用，提供单条或全部清理；确认清理前展示数量和空间，明确仅清理下载副本 |
| 空间限制 | 有单项和总缓存预算，界面展示当前限制；达到上限停止并提供清理，不静默删除用户明确下载的内容 |

## 3. 数据与权限规则

- 清理下载保留收藏、阅读进度和聊天记录；取消收藏默认不删除下载，若希望一起删除须明确选择。
- 好友私有内容只有允许获取时才能下载；下载动作作为接收者保存本地副本，拥有者撤销不能远程抹除。
- 撤销之后不得再从拥有者获取新版本；若产品不允许永久副本，应禁止离线保存，不能承诺可撤回的离线副本。
- 删除下载后同步清理其全文搜索索引，标题等仍存在于收藏的元数据可保留；另一份合法独立副本不误删。
- 离线进度先在本地保存，多设备传递由需求 08 决定。

## 4. 异常与范围

空间不足、权限失效、超限、正文提取失败、校验失败分别提示并给出动作。
下载中断后保持旧副本可用；不支持断点的来源明确重新下载，不能虚报续传。
首版不包含完整视频/音频、登录网页镜像、整站下载或后台无限自动更新。

## 5. 验收标准

同时满足 [通用验收标准](README.md#通用验收标准)。

| 编号 | 操作或条件 | 通过条件 |
|---|---|---|
| OFFLINE01 | 对支持的文章下载，随后断网并重启 | 本地正文可打开，来源/下载时间可见，无需发外网请求加载正文 |
| OFFLINE02 | 普通收藏但未下载，在断网时打开 | 清楚显示正文未下载，不错误显示可离线 |
| OFFLINE03 | 正文成功、部分图片失败 | 正文可读，图片缺失有标记，不显示完整资源已下载 |
| OFFLINE04 | 中途断网、取消、重启、连续点击下载 | 状态恢复正确，仅一份结果；未校验片段不标可读 |
| OFFLINE05 | 已有旧版，更新时断网或校验失败 | 旧版仍能读；新版本验证后才替换，并更新下载时间 |
| OFFLINE06 | 空间不足或超过单项/总预算 | 提示清理/超限，其他下载不静默丢失，应用仍可阅读 |
| OFFLINE07 | 单条/全部清理下载 | 对应磁盘空间释放，列表更新；收藏、进度、会话保留，正文索引及时移除 |
| OFFLINE08 | 无正文、需登录、已失权内容尝试下载 | 返回实际失败原因，不产生空的成功记录，不绕过授权 |
| OFFLINE09 | 已获授权下载，再撤销好友权限 | 本地副本仍按保存规则可读，界面不承诺远程回收；新版本获取被拒绝 |
| OFFLINE10 | 离线阅读后退出重开，再联网 | 阅读进度保持，外链仅主动打开时访问；无追踪脚本自动执行 |

需提交：断网重启阅读、部分资源失败、下载恢复、版本替换与空间清理记录。

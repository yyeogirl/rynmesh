# 01 首次阅读体验

状态：需求草案，待开发与验收。优先级：第一批，与配对分享同时推进。

## 1. 目标与流程

新用户无需账号、模型或好友，即可读到真实内容并收藏，知道来源失败时如何继续。

打开应用 → 准备来源 → 展示真实内容 → 打开阅读 → 收藏或反馈 → 首页继续使用。

首次引导可关闭；关闭不等于完成，下次可从首页继续。完成后提供“连接朋友”的非阻塞入口。

## 2. 功能需求

| 功能 | 具体规则 |
|---|---|
| 首屏内容 | 显示标题、来源和可用的发布时间；正常来源下首批 3–5 条，实际不足时按真实数量展示 |
| 真实来源 | 不使用演示卡片冒充内容；有其他节点的真实内容时标注“来自 Ryn 网络” |
| 阅读器 | 显示来源、正文和返回入口；提取失败时说明原因，允许用户主动打开原文 |
| 收藏 | 可收藏、取消和在已保存列表找回；重复操作不产生重复条目 |
| 阅读进度 | 保存已打开状态和阅读位置；重开同一内容可继续，未下载正文不承诺离线可读 |
| 首次完成 | 由真实内容成功打开并成功收藏或反馈判定，失败点击不算完成 |
| 来源健康 #16 | 逐来源展示状态、内容数、最近检查/成功时间、连续失败次数和缓存使用情况 |
| 来源恢复 | 可单独重试失败来源，不强制刷新全部正常来源，已有内容保留 |
| 反馈解释 #17 | 支持 More/Less/Hide，展示哪条操作、何时产生了哪些主题/平台/来源/内容信号 |
| 反馈撤销 | 可单独撤销一次反馈并重新计算推荐，不要求重置整个画像，不承诺某篇文章必定排第一 |

## 3. 异常与恢复

- 节点启动中显示进度状态；启动失败提供重试或诊断入口。
- 部分来源失败时继续显示其余内容；全失败有缓存时标注缓存时间。
- 全失败且无缓存时显示空状态和重试，联网后可以恢复。
- 无模型、无好友或 Registry 不可达，不阻断仍可用的公共来源与本地缓存。
- 收藏/反馈保存失败时明确提示未保存，允许重试，不提前显示完成。

## 4. 范围与复用

复用已有推荐、阅读、收藏/进度和首次成功候选实现，新增接口与存储遵守主线规范。
本需求不包含模型安装、完整文件管理或自动下载全文；离线能力由需求 07 提供。

## 5. 验收标准

同时满足 [通用验收标准](README.md#通用验收标准)。

| 编号 | 操作或条件 | 通过条件 |
|---|---|---|
| READ01 | 干净安装、正常网络、无模型与好友 | 无配置看到真实内容并完成打开、收藏；记录耗时，建议启动至完成不超过 3 分钟 |
| READ02 | 关闭未完成引导后重启 | 应用可用，首页可继续，未错误标记完成 |
| READ03 | 收藏并阅读后重启 | 收藏仅一条，阅读位置可恢复 |
| READ04 | 一个来源失败，单独重试 | 显示对应错误与失败次数；正常来源内容保留且不强制重抓 |
| READ05 | 全部来源断网，分别准备有缓存和无缓存 | 有缓存可读且有标记；无缓存有恢复入口，联网重试后可用 |
| READ06 | 查看内置和自定义来源 | 所有健康字段真实，从未检查或从未成功有明确文字 |
| READ07 | 分别反馈 More/Less/Hide，再撤销一条 | 操作、时间和信号可见；仅撤销指定操作，重新计算排名，重启保持 |
| READ08 | 收藏/反馈写入失败，恢复后重试 | 不伪造成功；恢复后只有一条记录 |
| READ09 | 完成后再次启动 | 不强制重复引导，能继续阅读并找到连接朋友入口 |
| READ10 | 导出/擦除推荐数据，检查日志与网络 | 解释记录纳入相应范围，画像不发给模型或外部服务，日志无私有正文 |

需提交：首次阅读、来源失败恢复、反馈撤销的执行记录，以及打包应用启动耗时。

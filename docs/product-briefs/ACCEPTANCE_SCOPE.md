# 本轮验收范围确认

2026-09-14，用户明确回复：“没有mac，可以跳过，公网也可以跳过”。

- macOS 设备、原生桌面安装及两种 macOS 架构实机验收：用户同意跳过。
- 两个不同公网出口、跨 NAT 的实机验收：用户同意跳过。
- 八项用户功能、数据保留、权限、失败恢复和本机可执行的检查继续验收。上述豁免不能用于略过本机已经发现的功能问题。
- 使用 Windows 上已安装 wheel、实际页面及独立本机节点作为本轮运行环境。无需为满足旧桌面门槛新增 Windows 原生桌面支持。

本确认优先于原需求与历史记录中的 macOS/公网必测条件。原始用例仍保留，不把未测的平台写成通过。收尾结果应区分本机通过、真实未完成问题及用户同意跳过。
